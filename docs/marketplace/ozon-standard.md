# Ozon Marketplace Standard

# Purpose

This document defines the standard for creating and maintaining product listings on the Ozon marketplace.

Every EFA product listing must follow these rules.

---

# Main Objective

Create product listings that are:

- technically accurate;
- easy to understand;
- optimized for Ozon search;
- trustworthy for customers.

---

# Product Title

The title should always include:

- Product type
- Brand (EFA / ЭФА)
- Main feature
- Vehicle compatibility (when appropriate)

The title must not contain:

- clickbait;
- excessive capitalization;
- unsupported claims.

---

# Product Description

Every description should explain:

- what the product is;
- its purpose;
- key benefits;
- technical features;
- compatibility information (only if verified).

Descriptions must be structured into short paragraphs.

---

# Product Attributes

All available Ozon attributes should be completed.

Missing information must never be invented.

---

# Images

Images should:

- clearly show the product;
- have a clean background;
- display the EFA brand consistently;
- avoid misleading visual elements.

---

# Customer Questions

If compatibility cannot be confirmed:

Ask the customer for:

- OEM number;
- VIN number;
- vehicle make;
- model;
- production year.

Never guess compatibility.

---

# Customer Reviews

Always respond:

- politely;
- professionally;
- concisely.

Never argue with customers.

---

# SEO Principles

Use natural language.

Include important search terms where appropriate.

Do not overload listings with keywords.

---

# AI Rules

AI must:

- follow EFA standards;
- use verified information;
- clearly indicate uncertainty when needed;
- never create fictional specifications.

---

# Quality Checklist

Before publishing, verify:

- Product title
- Description
- Attributes
- Images
- Compatibility
- OEM numbers
- Brand name
- Article number
